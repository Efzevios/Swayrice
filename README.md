## Aplicações
### Uso geral
* **WM:** Sway
* **Barra:** Waybar
* **Terminal:** Foot
* **Lançador:** Fuzzel
* **Notificações:** Mako
* **Movimentação:** Wl-kbptr
### Estética
* **Tema:** Colloid Dark Gruvbox
### Gerenciamento
* **Bluetooth:** Blueman
* **Wifi:** Network-manager
* **Áudio:** Pavucontrol
